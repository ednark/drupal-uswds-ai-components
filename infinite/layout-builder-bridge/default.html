USWDS Layout Builder Bridge — Custom Module

Bridges uswds_paragraph_components bundles into Drupal's Layout Builder via a reusable block_content type.

Architecture

Layout Builder section (layout plugin emits grid-row, grid-gap)
└── block_content: uswds_paragraph_blocks (placed inline)
    └── field_uswds_bundles (ER revisions, unlimited)
        ├── paragraph: uswds_card_group_regular
        │   └── uswds_card (children)
        ├── paragraph: uswds_alert
        └── paragraph: uswds_accordion
            └── uswds_accordion_item (children)

Reference implementation

pandemicoversight.gov (Drupal 11) ships prac_additional_uswds_paragraph_components with this exact pattern. The block-content--type-uswds-paragraph-blocks bundle wraps field_uswds_bundles and is placed via Layout Builder into grid-row grid-gap sections.

Why this tile exists

The other paragraph_bundle tiles describe attaching a Paragraphs field to a content type — fine for simple pages. Editorial landing pages with arbitrary layout need the bridge recipe: one block content type, reusable across any Layout Builder section, holding any mix of USWDS paragraph children.
