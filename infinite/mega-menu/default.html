USWDS Mega Menu Header — Custom Twig Variant

Implements the extended header with a mega menu pattern seen on gsa.gov, wrapping TB Mega Menu output inside USWDS usa-nav chrome.

Reference implementation

gsa.gov: <header class="usa-header usa-header--extended"> with <nav class="tbm tbm-main tbm-arrows" data-breakpoint="1200"> inside <div class="usa-nav__inner">. Each top-level item opens a mega menu panel with subnav lists plus a final usa-featured--topics column rendering a separate Drupal menu with link descriptions.

Why this tile exists

The base header/default.html tile covers standard USWDS basic and extended headers using the theme's built-in usa-nav__primary usa-accordion. Large agency sites (gsa.gov, ferc.gov) need richer mega menu panels with featured columns — this variant documents that integration.

Markup pattern (simplified)

<header class="usa-header usa-header--extended">
  <div class="usa-navbar">...logo...</div>
  <div class="usa-nav overlay-trigger" role="navigation">
    <div class="usa-nav__inner">
      <nav class="tbm tbm-main" data-breakpoint="1200">
        <ul class="tbm-nav level-0">
          <li class="tbm-item tbm-item--has-dropdown">
            <button class="tbm-link tbm-toggle" aria-expanded="false">Buy through us</button>
            <div class="tbm-submenu">...subnav...</div>
          </li>
        </ul>
      </nav>
    </div>
  </div>
</header>
