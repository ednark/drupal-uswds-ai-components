USWDS Icon List & Collection — Custom Paragraph Bundles

Extends uswds_paragraph_components with two custom paragraph bundles that contrib does not ship, following the pattern observed on pandemicoversight.gov.

Why this tile exists

The existing paragraph_bundle tiles cover what contrib ships (accordion, alert, card, modal, process-list, step-indicator, summary-box). Several federal sites need usa-icon-list and usa-collection as paragraph bundles too. Rather than wait for upstream contrib, sites build a small {project}_additional_uswds_paragraph_components module.

Reference implementation

pandemicoversight.gov (Drupal 11) ships prac_additional_uswds_paragraph_components with two submodules visible in CSS paths:

/modules/custom/prac_additional_uswds_paragraph_components/modules/prac_uswds_collection/css/prac_uswds_collection.css
/modules/custom/prac_additional_uswds_paragraph_components/modules/prac_uswds_icon_list/css/prac_uswds_icon_list.css
